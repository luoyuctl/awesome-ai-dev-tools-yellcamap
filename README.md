## Contributing

Found a tool that belongs here? Open a PR! Please include:

- A brief, honest description (no marketing copy)
- Evidence the tool is actively maintained
- Your genuine experience using it (if applicable)

We prioritize tools that are **open-source**, **AI-native or AI-friendly**, and **solving real problems**.

## Why This List?

The AI developer tools landscape moves fast. New tools launch weekly, established tools pivot to AI, and yesterday's breakthrough becomes today's baseline. This list exists to help developers cut through the noise and find tools that genuinely improve their workflow.

Inspired by the storytelling approach of [Yell Repo](https://repo.hoangyell.com/) and the structured tooling philosophy of projects like [Markdy](https://markdy.com/) and [Yellorn](https://yellorn.com/).
